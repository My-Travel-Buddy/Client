# My Travel Buddy

My Travel Buddy is an AI-powered travel planning platform that helps users generate, save, customize, and manage trip itineraries and preparation checklists.

## MVP Summary

A guest can generate an itinerary without logging in. Authentication is required only when the user wants to save the trip.

The final MVP includes:

- Public trip-planning form
- Guest AI itinerary generation
- Signup, login, session check, and logout
- Saved trips dashboard
- Trip CRUD
- Activity CRUD
- Full checklist CRUD
- Manual activity creation
- AI failure handling
- Deployment to Vercel, Render, and Neon
